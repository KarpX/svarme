## 🎮 Об игре

**SvarMe** — многопользовательская «Своя игра» для Telegram-групп. До четырёх игроков соревнуются в знаниях: выбирают категории и стоимость вопроса, нажимают кнопку «Ответить!» и зарабатывают очки за верные ответы. Правильный ответ приносит очки и право выбора следующего вопроса — неверный забирает их. Побеждает тот, кто наберёт больше всех к финальному раунду.

### Игровые режимы

| Режим        | Описание                                              |
| ------------ | ----------------------------------------------------- |
| **Стандарт** | 3 раунда, категории с нарастающей стоимостью вопросов |
| **Блиц**     | Ускоренный режим с 3 категориями и 3 вопросами        |

### Финальный раунд

Игроки с положительным счётом выходят в финал — делают ставку, получают вопрос в личные сообщения и пишут ответ. Победитель определяется по итоговому балансу после финала.

## 🛠 Технологии

- **Python 3.11+**
- **aiohttp** — асинхронный веб-сервер и HTTP-клиент
- **SQLAlchemy 2.0** (async) + **asyncpg** — работа с БД
- **PostgreSQL** — хранилище данных
- **Alembic** — миграции
- **Pydantic v2** — валидация Telegram Updates
- **Redis** — rate limiting
- **Docker Compose** — окружение

---

### Архитектурные слои

```
Telegram API
     ↓  long polling
TgApiAccessor → Poller
     ↓
BotManager (обработка Updates)
     ↓
BotRouter (роутинг команд / callback)
     ↓
Handlers (бизнес-логика)
     ↓
GameAccessor / UserAccessor / QuizAccessor
     ↓
PostgreSQL (SQLAlchemy async)
```

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/SvarMeBot.git
cd SvarMeBot
```

### 2. Настройка конфигурации

```bash
cp config.yml.example config.yml
```

```yaml
# config.yml
bot:
  token: "YOUR_TELEGRAM_BOT_TOKEN"

database:
  host: localhost
  port: 5432
  user: bot_user
  password: bot_password
  name: bot_database

redis:
  host: localhost
  port: 6379

gigachat:
  token: "YOUR_LLM_TOKEN_HERE"
```

### 3. Запуск через Docker Compose

```bash
docker-compose up -d
```

### 4. Запуск локально

```bash
# Установка зависимостей
pip install -r requirements.txt

# Применение миграций
alembic upgrade head

# Запуск
python -m app.web.app
```

## 🔄 Игровой процесс

```
Создание лобби (2–4 игрока)
        ↓
Выбор режима игры
        ↓
Раунд 1 → Раунд 2 → Раунд 3
┌──────────────────────────────────┐
│  Выбор категории и стоимости     │
│  Вопрос → кнопка «Ответить!»     │
│  Первый нажавший отвечает        │
│  Верно → +очки, право выбора     │
│  Неверно → -очки, кнопка снова   │
│  Никто не ответил → -очки за     │
│  таймаут, право выбора дальше    │
└──────────────────────────────────┘
        ↓
Финальный раунд
  Удаление категорий → Ставки → Вопрос в личку → Итоги
        ↓
Итоговый рейтинг + обновление статистики
```

### Таймеры

| Фаза                      | Время  |
| ------------------------- | ------ |
| Выбор вопроса             | 30 сек |
| Нажать кнопку «Ответить!» | 20 сек |
| Написать ответ            | 15 сек |

## 🔐 REST API (Admin)

| Метод    | Endpoint                           | Описание                      |
| -------- | ---------------------------------- | ----------------------------- |
| `POST`   | `/admin/login`                     | Авторизация администратора    |
| `POST`   | `/admin/logout`                    | Деавторизация адиминистратора |
| `GET`    | `/admin/categories`                | Просмотр всех категорий       |
| `POST`   | `/admin/categories`                | Создание категории            |
| `PATCH`  | `/admin/categories?category_id=id` | Обновление категории          |
| `DELETE` | `/admin/categories?category_id=id` | Удаление категории            |
| `GET`    | `/admin/questions`                 | Список вопросов               |
| `POST`   | `/admin/questions`                 | Создание вопроса              |
| `PATCH`  | `/admin/questions?question_id=id`  | Обновление вопроса            |
| `DELETE` | `/admin/questions?question_id=id`  | Удаление вопроса              |
